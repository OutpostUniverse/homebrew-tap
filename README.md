# OutpostUniverse Tap

## How do I install these formulae?

`brew install outpostuniverse/tap/<formula>`

Or `brew tap outpostuniverse/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "outpostuniverse/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
